# 🇪🇹 Ethio CSE AI

### Learn. Build. Innovate.

**An AI-powered academic and career companion built to empower Ethiopian Computer Science and Computing students.**

Ethio CSE AI is an intelligent learning assistant designed to support Ethiopian university students throughout their academic and professional journeys. It combines artificial intelligence, personalized learning support, programming assistance, and career guidance to help students learn more effectively, solve problems, and develop practical skills.

The goal is simple: make quality technical guidance, learning resources, and AI-powered assistance more accessible to Ethiopian students.

---

## 🎯 Project Vision

To build an intelligent ecosystem that bridges the gap between theoretical computer science education and practical technology skills in Ethiopia.

Ethio CSE AI aims to help students move beyond memorizing concepts toward understanding, building, experimenting, and solving real-world problems.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/kebedegeleta942-bot/ethio-cse-ai.git
```

### 2. Navigate to the Project

```bash
cd ethio-cse-ai
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the appropriate backend directory and configure your Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key
```

**Important:** Keep your API keys private. Never commit `.env` files or expose secret credentials in frontend code.

### 5. Start the Development Server

```bash
npm run dev
```

Refer to the individual frontend and backend package scripts if your local project uses separate application directories.

## 🌍 Why Ethio CSE AI?

Technology is transforming the world, but access to personalized technical guidance and practical learning opportunities is not equal everywhere.

Ethio CSE AI is an attempt to make that gap smaller.

We believe Ethiopian students have the potential to become innovators, engineers, researchers, and technology leaders. With the right tools, guidance, and opportunities, they can build solutions not only for Ethiopia but for the world.

**We are not just building another AI chatbot. We are building a learning companion for the next generation of Ethiopian technology professionals.**
